# Digital Checklist Engine

A modern, responsive, zero-dependency digital checklist web application designed for fast task tracking and bulk list conversions.

## Features
- **Bulk List Import**: Paste raw unformatted text, lists with markdown bullets or numbers, and convert them instantly into interactive checklist items.
- **Multiple Named Lists (Tabs)**: Organize tasks into separate lists with custom names, easy switching, and deletion.
- **Drag-and-Drop Reordering**: Rearrange items to prioritize your workflow.
- **Priority & Due Dates**: Color-coded badges for High, Medium, and Low priorities, plus calendar deadlines with overdue alerts.
- **Live Search & Filters**: Search tasks in real-time or filter by All, To Do, and Done.
- **Audio Feedback & Confetti**: Sound effects on task completion and celebration confetti when reaching 100%.
- **Export & Backup**: One-click copy to clipboard formatted in Markdown, or full JSON export/import.
- **Zero Dependencies**: Pure HTML5, CSS3, and JavaScript with localStorage persistence. Works 100% offline.

## Usage
Simply open `index.html` in any modern web browser or deploy directly to **GitHub Pages**!
